Проблемы и риски подписания агентского соглашения с ещё пятью страховыми компаниями:

- Увеличение кол-ва страховых компаний в 2 раза - это увеличение кол-ва сторонних АПИ в 2 раза на один запрос.
- Возможно потребуется увеличить интервал запроса к ins-product-aggregator от core-app, т.к. в новых реалиях 15 минут может быть недостаточно для завершения регламентного задания.
- Увеличенный интервал запроса предполагает снижение актуальности локальной реплики данных, что может негативно сказаться на пользовательском опыте.

Решение: перевести взаимодействие core-app с ins-product-aggregator на Event Streaming, как наиболее чувствительное место в данном кейсе.
Т.к. сохранение агрегированных данных для core-app будет переведено на потоковую обработку, введение Transactional Outbox было бы избыточным, т.к. при такой схеме будет отсутствовать проблема двойной записи. Агрегированные данные в течение коротких интервалов времени будут записываться только в Kafka Topic, запись в БД core-app будет вестись независимо от этого.
